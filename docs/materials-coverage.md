# Material coverage (MA1)

Every asset material in `content/assets/*.json` (309 assets, 23 families, 8192 material uses), with the L4 texture slot
it resolves to in the **base** table (pre-MA1) and in the **imgmat** table (Renderer::Perf `imgmat`, on by default),
and the decision taken. Generated by `node tools/materials_audit.mjs --md <file>` (re-run after changing
`content/textures/textures.json`; the table below is its output). How slots work: `docs/textures.md`.

## Summary

| | replace (the image is the surface) | detail (image on a procedural pattern) | procedural only |
|---|---|---|---|
| Base (pre-MA1) | 1008 uses | 5311 | 1873 |
| imgmat | **2983** | 3607 | 1602 (of which 150 uses also show a substrate) |

Decisions, by family:

- **Structural masonry and render** (stone coursed / field / rubble, ashlar, limewash, plaster, brick, brickwork,
  concrete, bunker concrete): `replace` with MA1 sets (dressed limestone, coursed rubble, grey rubble, large ashlar, lime
  render, aged render, muted / worn brick, aged / weathered / stained concrete). The pattern's noise is skipped. Render
  and limewash show their substrate (field masonry, worn brick) through the macro exposure mask, more on worn copies.
  The macro texture adds broad tint, roughness and damp variation (1 sample).
- **Roofs**: slate → weathered slate, clay tiles → aged clay (`part` mapping keeps the courses along the slope); orange
  "slate"-pattern roofs (`tile_orange`) get the clay set.
- **Timber**: beams / logs / trims → weathered beam (`replace`, `part`, grain along the part); furniture woods (cherry,
  treads) and joinery → aged oak detail; doors / shutters → worn blue-grey paint; windows → worn white paint; trench and
  revetment boards (`wood_raw`) → weathered boards.
- **Interiors**: wall finish (pattern 20) → old plaster detail under the room's procedural finish (prints, wainscot, fading
  stay); floor finish codes → images (0 boards, 2 tomettes, 3 stone flags, 4 beaten earth; parquet stays procedural);
  paper → aged paper; rugs → woven rug detail.
- **Metal**: bare steel → light rust, zinc → galvanised, field-grey / bunker-grey paint → worn painted metal; other metal
  slots kept.
- **Fabric**: sacking / hessian (sandbags, sacks) → olive canvas detail; other fabric slots kept.
- **Ground**: path dirt / gravel / concrete, painted dirt / gravel / leaf litter / cobbles and the terrain soil layer →
  compacted dirt, coarse gravel, leaf litter, worn paving; setts → worn paving.
- **Kept procedural**: glass, camouflage nets, faience and enamel glazes, dials, wallpaper prints (material rule `none`),
  and small flat colours (soot, stencils, water, lamps, flowers, ammunition markings). Existing good assignments
  (soil, turf, mud, sand, wicker, straw, leather, rust, painted military steel) are kept.
- **Damage faces**: breach cores (`rubble_core`) use the rubble substrate, `concrete_core` the aggregate concrete; brick
  rubble keeps its debris set.
